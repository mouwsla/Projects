# weather_prog

`weather_prog` — C++20-проект для оценки авиационных погодных рисков на маршруте. Программа читает JSON-сценарий с маршрутом, погодными опасностями, аэродромными условиями и параметрами воздушного судна, после чего формирует отчет о риске.

Проект состоит из:

- `aviwx_core` — ядро с парсером сценариев, геометрией маршрута и risk engine;
- `aviwx` — консольная утилита для отчета по сценарию;
- `aviwx_tests` — базовые тесты risk engine;
- `aviwx_app` — Qt GUI с картой, маршрутом, погодными слоями и профилем полета;
- `aviwx_gdal` — опциональная поддержка чтения SXF-карт через GDAL.

## Зависимости

Обязательные:

- CMake 3.20+
- компилятор с поддержкой C++20
- `make`

Опциональные:

- Qt6 Widgets и Qt6 Network — для сборки GUI-цели `aviwx_app`;
- GDAL — для чтения SXF-карт из `Maps/` и `Maps_1M/`.

Если Qt6 или GDAL не установлены, CMake пропустит соответствующие цели. Консольная утилита и тесты продолжают собираться без них.

## Сборка

Из каталога проекта:

```sh
make
```

По умолчанию используется директория сборки `build/make` и тип сборки `Release`. Их можно переопределить:

```sh
make BUILD_DIR=build/debug BUILD_TYPE=Debug
```

Полезные цели:

```sh
make aviwx      # собрать консольную утилиту
make app        # собрать GUI, если установлен Qt6
make test       # собрать и запустить тесты
make clean      # очистить артефакты через CMake
make distclean  # удалить текущую директорию сборки
```

## Запуск

Консольный отчет по демо-сценарию:

```sh
make run
```

То же самое вручную:

```sh
./build/make/aviwx examples/demo_scenario.json
```

Можно указать свой сценарий:

```sh
make run SCENARIO=examples/demo_scenario.json
```

GUI-приложение:

```sh
make run-app
```

С параметрами карты:

```sh
./build/make/aviwx_app --map-scale 200k --sxf-dir Maps examples/demo_scenario.json
./build/make/aviwx_app --map-scale 1m --sxf-dir Maps_1M examples/demo_scenario.json
```

Экспорт скриншота GUI:

```sh
./build/make/aviwx_app --screenshot screenshot.png --map-scale 200k --sxf-dir Maps examples/demo_scenario.json
```

## Формат сценария

Пример находится в `examples/demo_scenario.json`. Сценарий описывает:

- источник погодных данных;
- базовую карту;
- коридор маршрута;
- параметры самолета;
- точки маршрута и расчетное время пролета;
- погодные опасности с полигонами, высотами и временем действия;
- погоду на аэродромах и параметры ВПП.

Risk engine учитывает пересечение маршрута с зонами опасностей, высотный профиль, видимость, нижнюю границу облачности, боковой/попутный ветер и ограничения самолета.
