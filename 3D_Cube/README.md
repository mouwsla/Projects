# Вращающийся 3D-куб в консоли

Небольшая ASCII-анимация на C++17. Куб рисуется с перспективой, простым
освещением и z-буфером скрытых поверхностей.

## Запуск

```sh
make run
```

Управление:

- `C` — включить или выключить цвета граней
- `V` — включить или выключить ручное управление
- `WASD` или `→↑←↓` — вращать куб в ручном режиме
- `Ctrl+C` — остановить программу

По умолчанию цвета и ручное управление выключены, а куб вращается сам.

Дополнительные команды:

```sh
make        # только собрать ./cube
make clean  # удалить собранный файл
```
