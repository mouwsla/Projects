# Физическая модель и проверка результатов

## Galaxy (единицы kpc, Myr, Msun)

Ускорение в суммарном внешнем потенциале:

```
a(r) = -grad[ Phi_MiyamotoNagai + Phi_Hernquist + Phi_logHalo + Phi_softBH ]
```

- Disk: M = 6e10 Msun; a = 6.5 kpc, b = 0.26 kpc.
- Bulge: M = 1e10 Msun; a = 0.7 kpc.
- Halo: cored logarithmic potential, v0 = 180 km/s, rc = 3 kpc.
- Black hole: 4.2e6 Msun by default, softened at 0.004 kpc in the galaxy-wide solver.
- Integration: velocity Verlet; substep <= 0.5 Myr.
- Initial distribution: synthetic disk + bulge + halo tracers. Spiral overdensities are seeded in initial positions but not sustained by a density-wave model.
- Reference checks: numerical potential gradient and energy drift in static potential, plus coordinate finiteness.

**Important:** this is a test-particle calculation in an imposed potential; no star-star forces, tidal gas response, feedback, full dark-matter N-body distribution, or cosmological evolution.

## Galactic Center (units AU, Julian years, Msun)

Состояние хранится в барицентрической системе. Чёрная дыра и активные объекты получают парные ньютоновские ускорения, поэтому линейный импульс сохраняется (до ошибки RK4 и удаления обломков TDE). Между объектами также действует прямое N-body-притяжение. Для пары ЧД—объект добавляется 1PN-поправка Шварцшильда (предел тестовой частицы, гармонические координаты):

```
a = -mu*r/r^3 + mu/(c^2*r^3) * [ (4*mu/r - v^2)*r + 4*(r·v)*v ]
mu = G*M
```

Спин-орбитальная поправка Лензе—Тирринга:

```
a_LT = 2G/(c²r³) * [ 3(r·J)/r² (r×v) + v×J ]
J = a* G M²/c
```

Обратная реакция обеих PN-поправок передаётся чёрной дыре с отношением масс `m/M`. Интегратор — общий RK4 для всех координат и скоростей; максимальный шаг 0.003 года дополнительно уменьшается до `0.035 sqrt(r³/G(M+m))`.

S2 аппроксимирована через `a=1000 AU`, `e=0.884`, `m=14 Msun`, `R=7 Rsun` и выбранную визуальную ориентацию. Остальные тела синтетические. Одно из них (`TDE probe`) помещено на орбиту потерь для воспроизводимого события приливного разрушения.

Радиус разрушения:

```
r_t = R_object (M_BH/m_object)^(1/3)
```

Прямой захват приближён радиусом экваториальной предельно связанной орбиты Керра `r_mb = [2-a+2 sqrt(1-a)] r_g` для прямого движения и соответствующей формой с отрицательным `a` для обратного. Если `r_t > r_mb`, объект разрушается первым; половина массы считается аккрецированной. Иначе при пересечении `r_mb` масса захватывается целиком. При аккреции обновляются масса, барицентрическая скорость и проекция углового момента чёрной дыры.

**Важно:** 1PN/1.5PN — слабополевая модель, не точные времениподобные геодезические Керра. TDE не включает релятивистскую гидродинамику, самогравитацию обломков, fallback и джеты. Линии орбит — ньютоновские опорные эллипсы, а не распространённые траектории. Реальные эпохи и ошибки каталога S-звёзд не подогнаны.

## Black Hole

- Метрика Керра с `|a*| ≤ 0.998`; `r_g=GM/c²`.
- Горизонт: `r_+/r_g = 1 + sqrt(1-a*²)`.
- Экваториальный ISCO вычисляется по аналитической формуле через `Z1`, `Z2` (от `~1.237 r_g` для прямого `a*=0.998` до `~8.994 r_g` для обратного).
- Граница тени для удалённого наблюдателя строится из сферических фотонных орбит. Для каждого их радиуса вычисляются `ξ(r)`, `η(r)`, затем небесные координаты `alpha=-ξ/sin(i)`, `beta=±sqrt(η+a²cos²(i)-ξ²cot²(i))`. Полярный радиус границы табулируется в циклической 2048-точечной OpenGL-текстуре и меняется при изменении спина/наклона.
- Численная 2048-точечная таблица полного угла отклонения Шварцшильда сохранена для радиального искажения удалённого фона; ведущая спиновая асимметрия добавлена как тангенциальная поправка.
- Внутренняя граница тонкого диска совпадает с ISCO. Профиль потока использует нулевой момент на внутреннем крае `F ∝ r^-3(1-sqrt(r_ISCO/r))`; приближённые гравитационный и специальнорелятивистский множители образуют частотный сдвиг `g`, а наблюдаемая интенсивность масштабируется как `g³`.

**Важно:** точной является граница тени асимптотического наблюдателя, но не всё изображение. Фон не трассируется по полным нулевым геодезическим Керра от конечной камеры; диск не проходит GRMHD/радиационный перенос, не моделирует плазменное поглощение, магнитные поля, полную последовательность высших изображений и временную задержку.

### Высший образ аккреционного диска

Прямой почти реберный диск отображается отдельно от первого высшего изображения дальней стороны. Последнее концентрируется возле точной азимутально-зависимой границы захвата Керра. Его положение относительно критической кривой и асимметрия границы следуют из Kerr shadow LUT; перенос эмиссии вдоль дуги и её ширина являются real-time аппроксимацией. Поэтому характерные верхняя и нижняя дуги физически мотивированы, но их нельзя использовать для измерения субколец или параметров плазмы.

## Интегрированная геометрия и траектории света

Для `t=const`, `theta=pi/2` пространственная часть метрики Шварцшильда имеет вид:

```
dl² = dr²/(1-Rs/r) + r² dphi²
```

Её изометрическое вложение в евклидово трёхмерное пространство удовлетворяет:

```
dz/dr = sqrt(Rs/(r-Rs))
z(r) = 2 sqrt(Rs(r-Rs)) + const
```

Сцена строит поверхность и координатную сетку непосредственно по этой формуле для `1.015 Rs <= r <= 14 Rs`. Вертикальный ноль сдвинут так, чтобы удалённая часть сетки лежала в общей плоскости, но внутренняя геометрия от этого не меняется. Горизонт показан как горловина, а не как бесконечный цилиндр.

При ненулевом `a*` радиальные линии анимируются с направлением экваториальной угловой скорости ZAMO в геометрических единицах:

```
omega = 2 a r / ((r²+a²)² - a² Delta),   Delta=r²-2r+a²
```

Это иллюстрация frame dragging поверх шварцшильдовской поверхности; она не выдаётся за точное евклидово вложение полного пространственного среза Керра. Диаграмма не изображает временную координату, причинные конусы или «силу тяжести вниз».

В той же сцене и системе координат строятся экваториальные нулевые геодезические Шварцшильда. После введения `u=Rs/r` их точное орбитальное уравнение принимает вид:

```
d²u/dphi² + u = 3u²/2
```

Начальное состояние соответствует лучу, входящему слева с заданным impact parameter `b/Rs`. Система первого порядка для `(u,du/dphi)` интегрируется классическим RK4 с шагом `|dphi|=0.0025`. При `b <= 3 sqrt(3)/2 Rs` луч заканчивается на горизонте; при большем `b` выходит за исходную границу сцены. Для совместного отображения точки геодезической поднимаются на соответствующую высоту диаграммы Фламма. Это только способ совместной визуализации: физическая геодезическая определена метрикой, а не «скатывается» по поверхности.

Кадр компонуется в следующем порядке: поверхность и сетка → геодезические → тень и излучение диска. Поэтому горизонт непрозрачно перекрывает захваченные лучи, а остальная сетка остаётся видимой вокруг наблюдаемой чёрной дыры. Отдельного режима геометрии больше нет.

## Physics reference scene (нормированные единицы Rs=1, c=1)

Четвёртый режим воспроизводит наблюдаемую сцену `kavan010/black_hole`: центральная чёрная дыра и два солнечных объекта с начальными координатами `(31.521, 0)` и `(0, 31.521) Rs`, видимым радиусом `3.152 Rs` и отношением масс `m/M=2.329e-7`. В выбранных единицах `G M_BH = 1/2`, поэтому центральное ускорение равно:

```
a_BH = -r / (2 |r|^3)
```

Между объектами действует симметричная ньютоновская сила с тем же нормированием. Координаты и скорости интегрируются методом velocity-Verlet; шаг автоматически делится так, чтобы подшаг не превышал `0.02 Rs/c`. Как и в референсе, при выключенной гравитации состояние объектов полностью заморожено. При `r <= Rs` объект считается захваченным и возвращается в исходное положение — это дополнительное поведение Astrophysics Simulator.

Квадратная сетка содержит `25×25` ячеек с шагом `10^10 / 1.269·10^10 = 0.788 Rs`. Для каждого источника повторяется использованная референсом диаграмма вложения:

```
y_i(d) = 2 sqrt(Rs_i (d-Rs_i)) - 2.364,  d > Rs_i
```

Высоты трёх источников линейно суммируются, а сетка каждый кадр следует за объектами. Это повторяет визуальное поведение оригинала, но не является решением нелинейных уравнений Эйнштейна для нескольких тел.

Экранная трассировка использует те же размеры `200×150`, FOV `60°`, горизонт `Rs`, диск `2.2–5.2 Rs`, два цветных объекта и шварцшильдовские уравнения луча. Вместо OpenGL 4.3 compute shader расчёт выполняется в GLSL 330 fragment pass внутри RGBA8 framebuffer и затем альфа-компонуется поверх сетки. Благодаря этому один путь работает на macOS (контекст 4.1 Core), Linux и Windows.

### Встроенная диаграмма фотонов

Дополнительный слой поверх основной сцены Physics повторяет смысл предоставленной схемы фотонных траекторий. Девять лучей запускаются параллельно с impact parameters `6.0, 5.0, 4.0, 3.4, 3.0, 2.72, 2.61, 2.56, 2.35 Rs`. Для каждого используется то же точное экваториальное уравнение

```
d²u/dphi² + u = 3u²/2
```

и RK4 с шагом `|dphi|=0.0025`. Критическое значение равно `b_c=3√3 Rs/2≈2.598 Rs`: последние два луча захватываются, `b=2.61 Rs` совершает сильный околокритический оборот, остальные уходят на бесконечность. Отмеченные окружности имеют радиусы `Rs` (горизонт), `1.5 Rs` (фотонная сфера) и `b_c` (критическая кривая на диаграмме). Анимированные точки изменяют только отображение и не участвуют в интегрировании.

## Сверка с современной литературой (проверено 13.11.2026)

- Наблюдательная мотивация массы, кольца и геометрии Sgr A*: [EHT Collaboration, First Sgr A* Results I](https://arxiv.org/abs/2311.08680).
- 1PN-прецессия S2, измеренная около `12'` за оборот: [GRAVITY Collaboration (2020)](https://arxiv.org/abs/2004.07187).
- Гравитационное красное смещение S2 и релятивистский поперечный эффект Доплера: [GRAVITY Collaboration (2018)](https://arxiv.org/abs/1807.09409).
- Небесные координаты и параметрическая граница тени Керра: [Cunha & Herdeiro, coordinate-independent shadow characterization](https://doi.org/10.1093/mnras/stv2079) и [Teo, exact spherical photon orbits](https://arxiv.org/abs/2009.07012).
- 1PN-ускорение Лензе—Тирринга в современных эфемеридах: [Fienga & Minazzoli (2024)](https://doi.org/10.1007/s41114-023-00047-0).
- Стандартный и уточнённый критерий приливного разрушения: [Coughlin & Nixon (2022)](https://arxiv.org/abs/2209.03982).

## Example headless validation

```
cmake -S . -B build-headless -DASTRO_BUILD_GUI=OFF
cmake --build build-headless
ctest --test-dir build-headless --output-on-failure
```

Для научной публикации необходимы отдельные convergence-тесты, 2PN/3PN или точные геодезические, строгий бюджет энергии/углового момента, GR ray tracing от конечного наблюдателя, GRMHD-перенос излучения и сравнение с эталонными кодами.
